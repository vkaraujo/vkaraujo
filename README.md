# 👋 About Me

Hey there! I'm **Viktor Waissmann**, a Web Developer from Rio de Janeiro 🇧🇷.

💻 I specialize in **Ruby on Rails** and **React**, with experience building and maintaining scalable applications — from designing APIs and modeling databases to implementing automated tests and background jobs.

🚀 I've contributed to production-level apps at companies like **Mainô** and **Um a Mais**, where I worked on everything from bug fixes and new features to webhook integrations and background processing with Sidekiq.

🛠 My toolbox includes:
- Back-end: Ruby, Rails, REST APIs, PostgreSQL, Sidekiq
- Front-end: JavaScript, HTML, CSS, React
- Testing: RSpec, Cucumber, Capybara
- DevOps: GitHub Actions, Docker, AWS, Render
- Agile: Scrum, Kanban, Sprints

I love reading, playing Dungeons & Dragons, and grabbing a beer with friends.
